# Balkazar website

Official bilingual booking website for Balkazar, published with GitHub Pages at
[balkazar.org](https://balkazar.org).

## Key pages

- `/` — English booking site
- `/zh/` — Taiwan Traditional Chinese booking site
- `/zh/weiya/` — 尾牙／春酒 advertising landing page
- `/epk/` and `/zh/epk/` — electronic press kits
- `/gallery/` and `/zh/gallery/` — photo galleries
- `/band/` and `/zh/band/` — bilingual About the Band pages; Marko Djurasic is the only publicly featured individual musician pending consent from others
- `/marko/` and `/zh/marko/` — Marko Djurasic’s individual musician biography (accessible from Band)

## Musicians' consent

- Individual profiles, identifying biographies, standalone portraits, and named founding/current/former/guest credits for anyone other than Marko are unpublished pending their affirmative permission.
- Do not reintroduce roster names from old Git history into the public site/structured data/sitemap until permission is recorded privately in the existing ClickUp biography task.
- Publicly released live performance photos/video and press/event archives need a separate image/participant-consent review; this change only unpublishes individual musician pages, named roster entries, and references in Marko's biography.
